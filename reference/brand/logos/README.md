# Cyera logos (bundled, official)

These are the official Cyera logo files from the Employee Brand Kit → Logo Package.
Each version ships as **SVG** (use for HTML/web — crisp at any size) and **PNG**
(use for PowerPoint/Word, which can't embed SVG). All are 734×176 vector / 1468×352 px
raster, transparent background. Use them as-is — don't recolor, stretch, or redraw.

| File (use `.svg` for web, `.png` for decks/docs) | Version | Use on |
|---|---|---|
| `cyera-logo-black` | Primary, Black `#160923` | Light backgrounds (default) |
| `cyera-logo-white` | Primary, Offwhite `#FBFBFB` | Dark backgrounds (default) |
| `cyera-logo-black-green-symbol` | Secondary, black + green symbol `#7BF583` | Light bg, subtle brand pop |
| `cyera-logo-white-green-symbol` | Secondary, white + green symbol `#7BF583` | Dark bg, subtle brand pop |
| `cyera-logo-deep-purple` | Color, Deep Purple `#441363` | Light bg, color-forward |
| `cyera-logo-lilac` | Color, Lilac `#D28EFF` | Dark bg, color-forward |

Default to a primary mono logo (black on light, white on dark). Reach for a
green-symbol or color version for more brand-forward layouts.

The green in the symbol is `#7BF583` (the logo's own green) — it lives inside the
artwork and is logo-only. Don't sample it as a general accent or recolor the mark.
