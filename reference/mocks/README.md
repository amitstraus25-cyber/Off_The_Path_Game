# Branded UI mocks (visual source of truth for the DOM UI)
- `gameplay-concepts.*`: Explore, Question, Inspect, Arrive. The pixel art in the scenes is cropped from the concept board; the interface around it is the Cyera-branded rebuild.
- `results-leaderboard.*`: Results (recap, handle field, call to action) and the dark Leaderboard.
Open the `.html` files in a browser and copy CSS values into components. Superseded earlier leaderboard iterations were intentionally left out.
Sample handles and scores in the mocks are placeholders. The Results mock shows Night Light as malicious; see PLAN decision D1.
